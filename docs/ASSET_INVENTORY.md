# POPF Historical Asset Inventory

盘点日期：2026-09-18  
盘点范围：`data/raw/` 及其递归子目录  
盘点性质：只读资产盘点。未修改、移动、重命名、删除或清洗任何 raw 文件；未训练模型；未开发前端。

本文件记录目前历史资料库中可以被文件内容支持的事实。它不把文件名、目录名或数字自动解释成论文中的数据集，也不把后续网站资料自动解释成 2019 MLP 原始输入。

## 证据和关系标记

每项资产都按以下三层记录：

- **文件明确证明**：可以由文件内容、格式元数据、表格结构、压缩包目录或实际读取结果直接确认。
- **合理推断**：根据路径、字段、数量或重复关系得到的工作假设，但还没有完成历史用途核验。
- **目前无法确定**：当前资料不能支持的结论。后续必须保留为 `unknown`，不能批量补填。

历史关系使用以下标签：

- `2019 Original candidate`：与 2019 原始项目有较强线索，但尚未证明它就是论文中某个具体输入或输出。
- `Historical website material`：明显属于网站内容、页面设计、网站图片或网站数据整理阶段；不能自动等同于论文中的 MLP 数据。
- `Raw input for 2026 Reconstruction`：2026 重建可以读取和生成派生数据的原始来源，但不表示这些文件是 2026 新生成的。
- `Unknown`：历史用途、版本或来源尚不能确定。

优先级：

- `P0`：对复现或重建的核心链路非常关键。
- `P1`：对重建有明显帮助，但不一定是最小闭环的必需品。
- `P2`：可以参考、补充或用于人工核验，但不是当前最小闭环的必要条件。
- `P3`：暂时没有明显的重建用途，或属于系统/行政元数据。
