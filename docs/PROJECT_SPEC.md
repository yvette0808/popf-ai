# POPF 项目总说明

状态：`2026 Reconstruction / Modern Vision Baseline Complete`

本文件是 POPF（京剧脸谱数字传承）项目的总说明。它记录历史证据边界，以及已经实际运行的 2026 Reconstruction 数据和现代视觉 baseline；2019 原项目事实与现代重建结果必须继续严格分开。

## 1. 项目目标

最终目标是把原始图片、数据集、识别模型和知识服务整理成可复现的工程流程：

```text
原始图片 -> 数据集 -> 2019 MLP 基线复现 -> 现代 CNN 模型
        -> 图片识别 -> 脸谱知识关联 -> 用户反馈 -> Bad Case 分析
```

其中：

- `2019 Original` 是论文和原项目能够被资料证明的部分。
- `2026 Reconstruction` 是现在新增的目录、数据处理、模型实现、评估、知识关联和产品工程。
- 任何无法由资料证明的内容都标记为 `Unknown / To verify`。

## 3. 论文事实摘要

下列内容来自 `docs/2019_paper.pdf`，主要对应 PDF 第 2-6 页、论文印刷页 316-320。

### 3.1 数据规模和来源

- 论文称收集了总计 272 张带标签的正面脸谱图片，用于创建包含 16 种类型的训练数据集。[PAPER:P2-P3]
- 这些 272 张图片来自英文京剧介绍网站 `http://www.paulnoll.com`。[PAPER:P3]
- 论文另称从各种搜索引擎收集了约 200 张图片，用于测试识别模型的准确性。[PAPER:P3]
- 论文在模型部分把数据集概括为“约 500 张图片”，其中包含 272 张带标签图片。[PAPER:P3]
- 论文没有给出每类样本数、约 200 张测试图片的逐文件清单、文件名、原始 URL 或固定测试集版本。[UNKNOWN]

“272 + 约 200”与“约 500”之间存在四舍五入或数据范围定义不清的问题。本项目不自行修正这个差异。

### 3.2 数据字段

论文的 Table 1 展示了一个典型脸谱数据记录，明确出现的字段是：

### 3.3 16 类体系

论文明确说训练数据包含 16 种类型，模型也会计算图片属于 16 个类别的概率。[PAPER:P2-P4]

论文正文明确写出的类别或示例术语如下，但这不是经过验证的完整 16 类表：

- `entire face`
- `three-tile face`
- `colored three-tile face`
- `six-tenths face`
- `fragmented pattern face`
- `cross-shaped pattern face`
- `pictographic face`
- `eunuch face`
- `goblin face`

其中，前六项中的六项（`three-tile face`、`fragmented pattern face`、`cross-shaped pattern face`、`pictographic face`、`entire face`、`colored three-tile face`）被论文明确说实际用于构建识别模型。[PAPER:P4]

论文还说明，因为只有这六类达到了至少 20 张图片的训练样本基线，剩余 10 类由于样本不足不能被当前识别模型分类。[PAPER:P4]

论文没有在正文给出完整 16 类名称和正式类别 ID。Figure 3.2 展示了模块页面的四个截图卡片，但截图中的小字无法作为完整类别字典可靠读取。[FIGURE][UNKNOWN]

### 3.4 原始图片处理

论文明确写出：

1. 输入图片包含 JPG 和 PNG 格式。
2. 论文描述图片包含正面和侧面脸谱，且原始尺寸不一致。
3. 带标签的 272 张图片被导入后按 4:1 比例划分训练数据集和测试数据集。
4. 所有导入图片转换为 `100 * 100` 灰度图。
5. 像素转换为浮点数，并归一化到 0 到 1。
6. 论文提到计算像素值的算术值和像素均值，并在 KNIME 的 Feature calculator 中选择图像特征。[PAPER:P3-P4]

论文没有说明裁剪、缩放插值、纵横比处理、背景处理、通道排列、像素展平方式、特征向量维度、均值的具体用途或缺失图片处理方式。[UNKNOWN]

### 3.5 MLP 模型流程

论文称使用 KNIME 构建识别模型，使用 MLP（Multilayer Perceptrons）算法。[PAPER:P2-P4]

正文和 Figure 2 能确认的流程包括：

1. 导入带标签图片。
2. 图像预处理。
3. 使用 Feature calculator 选择图像特征。
4. 在 Learning node 中使用 MLP。
5. 对 16 个类别计算归属概率，并将最高概率类别作为识别结果。
6. 使用 Partitioning node 划分训练集和测试集。
7. 使用 10-fold cross-validation 评估模型。
8. 论文图中还出现 `SimpleMLP`、`Learning`、`Prediction`、`Equal Size Sampling` 和 `Data Presentation` 等节点或模块名称。[FIGURE]

论文没有说明 MLP 的层数、隐藏单元、激活函数、优化器、学习率、迭代次数、正则化、停止条件、特征维度、节点具体参数或 KNIME 版本。[UNKNOWN]

### 3.6 训练/测试划分和 10-fold cross-validation

论文有两段相关描述，不能在当前阶段擅自合并：

- 数据收集与图像处理部分：272 张带标签图片按 4:1 比例划分为训练数据集和测试数据集。[PAPER:P3]
- 模型评估部分：Partitioning node 随机取 80% 图片为训练集，其余为测试集；模型在 10-fold cross-validation 后的准确率约为 70%。[PAPER:P4]

论文没有说明：

- 4:1 划分与后续 80/20 Partitioning 的先后关系。
- 10 个 fold 是否在固定外层测试集之外进行。
- 是否使用分层划分。
- 随机种子、重复次数、fold 结果、汇总方式和置信区间。

因此，2026 重建必须把这两段作为待验证的实验协议，而不是擅自写成唯一正确的 2019 流程。

### 3.7 网站功能

论文描述的网站有两个主功能：

1. 连接图片数据库，动态展示数据库中的图片及相关信息。
2. 提供上传入口，用户上传脸谱图片后由识别模型返回反馈。[PAPER:P4]

网站页面/模块包括：

- welcome page：介绍京剧脸谱并引导用户进入学习环境。
- modules page：展示 16 类图标，点击后查看代表性图片及相关介绍。
- upload port：通过大号“+”上传图片，返回最高概率的类别。
- about us：论文把它列为网站组成部分，但没有给出详细内容。[PAPER:P5]

论文举例说明，用户上传 Kong Xuan 的脸谱时，网站可能给出 goblin face 作为最可能类别；结果页还会出现 `yes` 和 `no` 图标，用户可对结果进行反馈。[PAPER:P5]

### 3.8 数据库结构

论文只明确说使用 MySQL 保存图片及其关联信息，并展示了一个典型记录。[PAPER:P3]

论文没有提供可执行的数据库 schema。Table 1 的四个字段和网站文字中的信息项只能作为证据线索，不能直接当作 2019 数据库完整结构。

### 3.9 已报告结果

- 论文报告：使用 MLP 的识别模型在 10-fold cross-validation 后准确率“约 70%”。[PAPER:P4]
- 该数值是 `2019 Original` 的论文报告值，不是本项目已经运行得到的结果。
- 论文没有给出准确率的精确小数、每个 fold 的结果、混淆矩阵、分类别指标、测试集文件或评估脚本。

### 3.10 已知局限

论文明确指出：

- 图片数据库规模较小。
- 训练数据各类型样本不均匀。
- 只有六类达到至少 20 张图片的训练数据基线。
- 当前模型无法分类剩余 10 类。
- 识别模型准确率不高。
- 网站内容还不充分。
- 后续需要收集更多高质量、不同类型的图片，改进识别模型并丰富网站内容。[PAPER:P4][PAPER:P6]

## 5. 2026 Reconstruction 当前实现状态

历史 raw 资料已经完成盘点，`data/processed/272_candidate/` 和
`data/processed/modern_dataset/` 已建立。现代数据集当前使用 XLS 实际标签，
不强制映射到论文的 16 类体系：

- 272 张历史图片均可读取；modern_v1 使用 222 张图片。
- modern_v1 使用 7 个实际标签：三块瓦脸、碎脸、象形脸、花三块瓦脸、整脸、十字门脸、六分脸。
- train/validation/test 为 154/34/34，跨 split SHA-256 重复为 0。
- Dataset 从历史 ZIP member 直接读取，默认输出 `[B, 3, 224, 224]`。
- 已完成 ImageNet 预训练、冻结 backbone 的 ResNet-18 baseline。
- 训练、验证和一次最终 test 评估的产物位于 `artifacts/` 和 `reports/`。

上述现代模型、划分、指标和代码全部属于 `2026 Reconstruction`，不能写成
`2019 Original`。2019 论文中的 KNIME/MLP 仍只作为历史背景，尚未被本项目复现。

## 6. 当前阶段结论

现代 Dataset/DataLoader 和第一版视觉 baseline 已经可以复现运行；模型结果仍受
数据规模、类别不平衡和验证/测试样本很少的限制。下一步应根据实际 bad case
和数据质量证据选择一个实验，不应直接宣称生产可用，也不应把当前结果与论文约
70% 的历史报告值做未经控制条件的优劣比较。

2019 MLP、KNIME 工作流、网站和知识库仍需在用户明确切换阶段后分别处理。详细
阻塞项和顺序见 `docs/TODO.md`。
